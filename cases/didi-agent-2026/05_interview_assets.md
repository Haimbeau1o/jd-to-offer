## 项目讲解顺序

1. 先讲业务问题：司机经营问题复杂且高频，需要比传统 FAQ 更强的决策链路
2. 再讲系统设计：intent router → planner/ReAct → tools → memory → evaluator
3. 再讲训练闭环：SFT 打底、偏好优化或可验证奖励提升工具调用和解释质量
4. 最后讲结果：离线评测、失败样例、下一步业务价值

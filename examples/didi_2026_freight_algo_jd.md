# 滴滴 2026 届货运算法工程师（供需策略）

## 岗位职责

1. 负责同城货运场景下的供需预测、履约风险建模与核心策略优化，支持区域、时段和车型维度的精细化决策。
2. 参与派单策略、订单曝光分发、司机侧激励与补贴策略设计，提升完单率、履约时效与补贴 ROI。
3. 结合订单、司机、区域和时空上下文构建特征体系，推动策略从离线分析走向线上落地与持续迭代。
4. 通过 AB 实验、离线评估或因果分析方法评估策略增量效果，沉淀可复用的评估框架与指标体系。
5. 与产品、运营、工程团队紧密协作，深入理解货运交易市场机制，推动策略能力模块化与平台化建设。

## 任职要求

1. 2026 届硕士及以上学历，计算机、人工智能、统计学、运筹学等相关专业优先。
2. 具备扎实的 Python 编程能力，熟悉常用机器学习建模流程，能够独立完成数据分析、特征工程和模型实验。
3. 熟悉预测、排序、策略优化、因果推断、强化学习或运筹优化中的至少一个方向，并理解其业务适用边界。
4. 对供需策略、交易市场或智能调度类问题有兴趣，能够把模型指标翻译为业务指标和策略收益。
5. 具备良好的沟通协作能力和快速学习能力，能够在复杂业务中快速抽象问题并推进落地。

## 加分项

1. 有网约车、货运、外卖、即时配送等双边交易平台相关实习或项目经验。
2. 使用过 OR-Tools、EconML、CausalML、LightGBM/XGBoost 等工具，做过优化、uplift 或策略评估相关实践。
3. 能将大模型能力用于运营分析、策略解释或报告生成，但不过度替代核心策略逻辑。

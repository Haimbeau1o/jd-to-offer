# Output Contract

## Required Files

### `01_jd_decomposition.md`
Summarize the JD structure, top competencies, matched keywords, and hidden expectations.

### `02_knowledge_system.md`
Break the JD into a detailed study tree. For each competency, include subtopics, project signals, and interview signals.

### `03_resource_pack.md`
List current high-quality resources with links, type, and relevance. Avoid generic blogspam.

### `04_project_blueprint.md`
Define one flagship project with architecture, modules, milestones, metrics, and demo scenarios.

### `05_interview_assets.md`
Provide resume bullets, project talking points, self-introduction framing, and likely interview questions.

### `manifest.yaml`
Record case metadata, source JD path, target company/role, generated timestamp, and competency tags.

## Review Checklist

- Is the study plan detailed enough to execute?
- Does the resource pack use current primary sources?
- Does the project blueprint feel role-specific rather than generic?
- Can the user explain both the technical path and the business value?
